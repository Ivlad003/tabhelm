Let your terminal agent drive the tab you're looking at Ваш терміналний агент керує вкладкою, яку ви бачите

TabHelm is a Chrome side panel chat. Pick Claude Code, Codex, Cursor, Antigravity, OpenCode, Qoder, Grok or free OpenRouter models — the agent runs on your machine with its own login and reads, clicks and types on the current tab of your real, logged-in browser. TabHelm — це чат у бічній панелі Chrome. Оберіть Claude Code, Codex, Cursor, Antigravity, OpenCode, Qoder, Grok або безкоштовні моделі OpenRouter: агент працює на вашому комп'ютері зі своїм логіном і читає, клікає та вводить текст на поточній вкладці вашого звичайного браузера.

Run the installerЗапустіть інсталятор

One command (bash or PowerShell) sets up the host and registers it with Chrome, Chromium, Brave and Edge.Одна команда (bash або PowerShell) встановлює хост і реєструє його в Chrome, Chromium, Brave та Edge.

Load the extensionЗавантажте розширення

Open chrome://extensions, turn on Developer mode, click Load unpacked and choose ~/.tabhelm/app/extension. To update later, run the installer again and press ↻ on that page.Відкрийте chrome://extensions, увімкніть Developer mode, натисніть Load unpacked і виберіть ~/.tabhelm/app/extension. Для оновлення запустіть інсталятор ще раз і натисніть ↻ на тій самій сторінці.

Connect an agentПідключіть агента

Click the TabHelm icon on any page, pick an agent and a model, press Connect and describe the task.Натисніть іконку TabHelm на будь-якій сторінці, оберіть агента й модель, натисніть Connect і опишіть завдання.

What the agent can doЩо вміє агент

Read the pageЧитати сторінку

Compact outline with element refs, text search, full text, screenshots — including iframes.Компактний конспект із посиланнями на елементи, пошук, повний текст і скриншоти, зокрема всередині iframe.

Act like a personДіяти як людина

Real (trusted) clicks, typing, hover, drag and drop, key combos, file uploads, scrolling and tabs.Справжні (trusted) кліки, введення, hover, drag & drop, комбінації клавіш, завантаження файлів, прокрутка й вкладки.

Debug your appНалагоджувати ваш сайт

Console messages, network requests and JavaScript evaluation for the tab you are building.Повідомлення console, мережеві запити й виконання JavaScript на вкладці, яку ви розробляєте.

Guide mode and skillsРежим гіда і скіли

Ask to be shown how: an arrow and instruction appear on the page for each step and the agent waits for your click. Then turn the chat into a reusable skill with one click.Попросіть показати, як: на кожен крок на сторінці з'являється стрілка з інструкцією, а агент чекає вашого кліку. Потім перетворіть чат на скіл одним кліком.

Record what it didВідео того, що зробив агент

One switch records every task as a video with a visible agent cursor, saved to ~/Videos/TabHelm.Один перемикач — і кожне завдання записується на відео з видимим курсором агента та зберігається в ~/Videos/TabHelm.

Switch agents mid-chatЗміна агента посеред чату

Pick another CLI at any time, or continue with one click when an agent fails — the next one gets the chat and every action taken. Export the chat and action log as Markdown or JSON.Оберіть інший CLI будь-коли або продовжте одним кліком, якщо агент упав: наступний отримає чат і всі виконані дії. Чат і журнал дій можна експортувати в Markdown або JSON.

History that staysІсторія, що не зникає

Every chat is saved on your computer with search, delete and Clear all. The host keeps a backup, so reinstalling the extension does not lose it. Replies render as full Markdown.Кожен чат зберігається на вашому комп'ютері: пошук, видалення, Clear all. Хост тримає резервну копію, тож перевстановлення розширення нічого не губить. Відповіді показуються як повноцінний Markdown.

Stay in controlКонтроль за вами

One tab per chat. Uploads, scripts and other tabs always ask first; every action is logged in the panel.Одна вкладка на чат. Завантаження файлів, скрипти й інші вкладки завжди потребують підтвердження, а кожна дія видна в панелі.
