1. Requirements1. Що потрібно

  • Node.js 20+ — nodejs.org. Check with node -v.Node.js 20+ — nodejs.org. Перевірка: node -v.
  • Chrome, Chromium, Brave or Edge on Linux, macOS or Windows 10/11.Chrome, Chromium, Brave або Edge на Linux, macOS чи Windows 10/11.
  • At least one agent: a CLI you already use (Claude Code, Codex, Cursor agent, OpenCode, Qoder, Antigravity, Kilo, Cline, CodeBuddy, Grok) or a free OpenRouter key for the built-in agent or Ollama with a model. Nothing else — no accounts with TabHelm, no cloud.Хоча б один агент: CLI, яким ви вже користуєтесь (Claude Code, Codex, Cursor agent, OpenCode, Qoder, Antigravity, Kilo, Cline, CodeBuddy, Grok), або безкоштовний ключ OpenRouter для вбудованого агента, або Ollama з моделлю. Більше нічого — жодних акаунтів TabHelm чи хмари.

2. Install the host2. Встановіть хост

The host is a small Node program that Chrome starts on demand; it launches your agents and bridges them to the panel. One command installs it into ~/.tabhelm/app and registers it with every supported browser.Хост — маленька програма на Node, яку Chrome запускає за потреби; вона запускає ваших агентів і з'єднує їх із панеллю. Одна команда встановлює його в ~/.tabhelm/app і реєструє в усіх підтримуваних браузерах.

Linux / macOS

curl -fsSL https://ivlad003.github.io/tabhelm/install.sh | bash

Windows — PowerShell

irm https://ivlad003.github.io/tabhelm/install.ps1 | iex

Windows — Command Prompt (cmd)

powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://ivlad003.github.io/tabhelm/install.ps1 | iex"

The installer downloads the latest release, runs npm ci for the host and writes the native-messaging manifest (files under ~/.config/…/NativeMessagingHosts on Linux, ~/Library/Application Support/… on macOS, registry keys under HKCU on Windows). It ends by printing the folder to load in the next step.Інсталятор завантажує останній реліз, виконує npm ci для хоста й записує маніфест native messaging (файли в ~/.config/…/NativeMessagingHosts на Linux, ~/Library/Application Support/… на macOS, ключі реєстру в HKCU на Windows). Наприкінці він показує папку для наступного кроку.

The installer records your current PATH, because Chrome starts the host with a minimal environment. After installing a new CLI, run the installer again so the host can find it.Інсталятор запам'ятовує ваш поточний PATH, бо Chrome запускає хост із мінімальним оточенням. Після встановлення нового CLI запустіть інсталятор ще раз, щоб хост його знайшов.

3. Load the extension3. Завантажте розширення

  1. Open chrome://extensions (brave://extensions, edge://extensions).Відкрийте chrome://extensions (brave://extensions, edge://extensions).
  2. Turn on Developer mode (top right).Увімкніть Developer mode (праворуч угорі).
  3. Click Load unpacked and choose ~/.tabhelm/app/extension (%USERPROFILE%\.tabhelm\app\extension on Windows).Натисніть Load unpacked і виберіть ~/.tabhelm/app/extension (%USERPROFILE%\.tabhelm\app\extension на Windows).
  4. Optional: pin TabHelm in the toolbar (puzzle icon → pin).За бажанням закріпіть TabHelm на панелі інструментів (іконка пазла → шпилька).
The extension's ID is fixed by a key in its manifest, so the host's manifest always matches it — no need to copy IDs around.ID розширення зафіксований ключем у маніфесті, тож маніфест хоста завжди йому відповідає — нічого копіювати не треба.

4. First chat4. Перший чат

  1. Open any page and click the TabHelm icon — the side panel opens for this tab.Відкрийте будь-яку сторінку й натисніть іконку TabHelm — бічна панель відкриється для цієї вкладки.
  2. Pick an agent in the list (only installed ones are enabled; the others show how to install them) and, if you like, a model next to it.Оберіть агента в списку (активні лише встановлені, решта показує, як їх поставити) і за бажанням модель поруч.
  3. Type a task — “Find the cheapest item on this page and open it” — and press Send. The agent starts with your first message; the first run may ask you to sign in (a browser window opens).Напишіть завдання — «Знайди найдешевший товар на цій сторінці й відкрий його» — і натисніть Send. Агент стартує з першим повідомленням; перший запуск може попросити увійти (відкриється вікно браузера).
  4. Watch the Steps block: every click, typed text and navigation is listed. Actions that change the page ask for approval unless Auto-approve is on.Стежте за блоком Steps: кожен клік, введений текст і перехід у списку. Дії, що змінюють сторінку, потребують підтвердження, якщо не ввімкнено Auto-approve.
The agent works in your real, logged-in browser. Give it tasks the way you would give them to a colleague at your keyboard, and keep Auto-approve off on sites where a wrong click costs money.Агент працює у вашому справжньому браузері з вашими логінами. Давайте йому завдання так, як дали б колезі за вашою клавіатурою, і не вмикайте Auto-approve на сайтах, де хибний клік коштує грошей.

6. Updating6. Оновлення

  1. Run the same install command again. It stops a running host, replaces ~/.tabhelm/app and re-registers the host.Запустіть ту саму команду встановлення. Вона зупинить запущений хост, замінить ~/.tabhelm/app і перереєструє хост.
  2. On chrome://extensions press ↻ on the TabHelm card, then reopen the panel.На chrome://extensions натисніть ↻ на картці TabHelm і знову відкрийте панель.

The panel checks this site's news.json once an hour and shows an Update banner when a newer release exists (Settings → Check for updates checks right away). Do not remove the extension to update — and if you do, your chats come back: the host keeps a backup in ~/.tabhelm/state.json.Панель раз на годину перевіряє news.json цього сайту й показує банер Update, коли є новіший реліз (Settings → Check for updates перевіряє одразу). Видаляти розширення для оновлення не потрібно — а якщо видалите, чати повернуться: хост тримає резервну копію в ~/.tabhelm/state.json.

8. Remote host (relay)8. Віддалений хост (relay)

Run the agents on a VPS or another computer while the panel stays in your Chrome. Both sides connect out to a tiny relay you host, so no SSH or open ports are needed.Агенти працюють на VPS чи іншому комп'ютері, а панель лишається у вашому Chrome. Обидві сторони підключаються назовні до маленького relay на вашому сервері, тож SSH чи відкриті порти не потрібні.

Deploy the relay (Dokploy or any Docker host)Розгорніть relay (Dokploy або будь-який Docker)

  1. Application from the repository, build path relay (Dockerfile).Application з репозиторію, build path relay (Dockerfile).
  2. Environment: RELAY_KEY = a long random string (openssl rand -base64 24).Змінна середовища RELAY_KEY — довгий випадковий рядок (openssl rand -base64 24).
  3. Domain relay.yourdomain.com → port 8080, HTTPS on. Check: curl https://relay.yourdomain.com/ → TabHelm relay: 0 host(s).Домен relay.ваш.домен → порт 8080, HTTPS увімкнено. Перевірка: curl https://relay.ваш.домен/ → TabHelm relay: 0 host(s).

Start the host on the remote machineЗапустіть хост на віддаленій машині

Install TabHelm there with the same command as in step 2 (registering it with a browser is not needed), sign the agents in once, then:Встановіть там TabHelm тією самою командою, що в кроці 2 (реєструвати в браузері не треба), один раз залогіньте агентів, а потім:

cd ~/.tabhelm/app/host
npm run relay -- wss://relay.yourdomain.com --key <RELAY_KEY> --name my-vps

The host prints a pairing code such as K7PM-3QWX (10 minutes, single use) and keeps running; keep it alive with tmux, systemd or run the agents in a container built from host/Dockerfile.agent (the code appears in the container log).Хост друкує код парування на кшталт K7PM-3QWX (10 хвилин, одноразовий) і працює далі; тримайте його живим через tmux, systemd або запустіть агентів у контейнері з host/Dockerfile.agent (код буде в логах контейнера).

Pair the panelСпаруйте панель

Settings → Remote host: relay URL + the code → Connect. The remote agents appear in the list. Use local host switches back (the pairing is kept), Forget pairing drops it.Settings → Remote host: URL relay + код → Connect. Віддалені агенти з'являться в списку. Use local host повертає до локального (парування зберігається), Forget pairing видаляє його.

The relay forwards page snapshots and screenshots in clear text inside TLS. Keep RELAY_KEY private and use only a relay you run yourself.Relay пересилає знімки сторінок і скриншоти у відкритому вигляді всередині TLS. Тримайте RELAY_KEY у секреті й користуйтеся лише власним relay.

9. Windows notes9. Нюанси Windows

  • Use the PowerShell command, or the cmd variant from a Command Prompt; curl … | bash does not work there.Використовуйте команду для PowerShell або варіант для cmd; curl … | bash там не працює.
  • The host is registered in the registry (HKCU\Software\Google\Chrome\NativeMessagingHosts\com.tabhelm.host, same for Edge, Chromium, Brave) and started through tabhelm-host.cmd.Хост реєструється в реєстрі (HKCU\Software\Google\Chrome\NativeMessagingHosts\com.tabhelm.host, так само для Edge, Chromium, Brave) і запускається через tabhelm-host.cmd.
  • Agents installed by npm (agent.cmd, Kilo, Cline…) are launched through cmd.exe — needed since Node 20.12.Агенти, встановлені через npm (agent.cmd, Kilo, Cline…), запускаються через cmd.exe — так вимагає Node від 20.12.
  • The folder picker is a PowerShell dialog; 1Password hand-off needs op.exe on PATH; tab-audio transcription needs ffmpeg + whisper-cli or a transcription API.Вибір папки — діалог PowerShell; передача з 1Password потребує op.exe у PATH; транскрипція звуку вкладки — ffmpeg + whisper-cli або API транскрипції.
